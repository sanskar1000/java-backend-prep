## 🧠 Key Concepts

### Java Program Structure

A basic Java program contains a class and a `main()` method.

Example:

    public class HelloWorld {

        public static void main(String[] args) {

            System.out.println("Hello, World!");
        }
    }

### Variables

A variable is a named location used to store a value.

Example:

    int age = 22;
    double salary = 50000.50;
    String name = "Aradhya";

General syntax:

    dataType variableName = value;

### Data Types

Java provides eight primitive data types:

- `byte`
- `short`
- `int`
- `long`
- `float`
- `double`
- `char`
- `boolean`

Java also provides reference types such as:

- `String`
- Arrays
- Classes
- Interfaces
- Objects

### Literals

A literal is a fixed value written directly in Java source code.

Examples:

    int number = 100;
    double price = 99.99;
    char grade = 'A';
    boolean isActive = true;
    String name = "Aradhya";

### Input and Output

Console output:

    System.out.println("Hello");

User input using `Scanner`:

    Scanner scanner = new Scanner(System.in);

    System.out.print("Enter your age: ");
    int age = scanner.nextInt();

### Type Casting

Type casting means converting a value from one data type to another compatible data type.

#### Widening Casting

Widening converts a smaller compatible type into a larger type.

Example:

    int number = 100;
    double value = number;

Example conversion:

    int → long → float → double

Widening conversion happens automatically.

#### Narrowing Casting

Narrowing converts a larger type into a smaller type.

Example:

    double value = 100.50;
    int number = (int) value;

Output:

    100

Narrowing conversion requires explicit casting.
