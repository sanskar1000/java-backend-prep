# Class and Object in Java

## What is a Class?

A class is a blueprint for creating objects.

In object-oriented programming (OOP), a class is a logical construct that defines:

* State (fields/attributes)
* Behavior (methods)

A class supports important OOP concepts such as:

* Encapsulation
* Inheritance
* Polymorphism

## What is an Object?

An object is an instance of a class.

It combines:

* Data
* Methods

into a single unit.

Objects communicate with each other through methods, forming the foundation of object-oriented programming.
