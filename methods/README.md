# Java Methods

A structured collection of Java programs demonstrating methods, method parameters, return types, method overloading, and practical method-based problem-solving.

This module focuses on writing reusable, readable, and maintainable Java code by breaking complex tasks into smaller, well-defined methods.

## 📌 Topics Covered

- Method Basics
- Methods with Parameters
- Methods with Return Types
- Method Overloading
- Method-Based Problem Solving
- Prime Number Checking Using Methods
- Method Declaration, Invocation, and Execution
- Reusability and Modular Programming
