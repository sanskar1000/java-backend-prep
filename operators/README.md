# Java Operators

This folder contains clean, well-documented Java code examples demonstrating various types of operators in Java, as part of the `java-backend-prep` repository.

---

## 📁 Files Included

* **`ArithmeticOperatorsDemo.java`**: Code examples covering standard arithmetic operations (`+`, `-`, `*`, `/`, `%`).
* **`AssignmentOperatorsDemo.java`**: Demonstration of assignment operators, including compound assignment operators (`=`, `+=`, `-=`, `*=`, `/=`, `%=`).
* **`LogicalOperatorsDemo.java`**: Logical operations using standard logical AND, OR, and NOT (`&&`, `||`, `!`).
* **`RelationalOperatorsDemo.java`**: Comparison operators used to compare two values (`==`, `!=`, `>`, `<`, `>=`, `<=`).
* **`TernaryOperatorDemo.java`**: Examples illustrating shorthand conditional expressions using the ternary operator (`? :`).
* **`UnaryOperatorsDemo.java`**: Demonstrations of unary operators including increment and decrement (`++`, `--`, `+`, `-`).
